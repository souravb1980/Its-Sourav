# Dr. Sourav Kumar Bhowmick | Academic Portal & Research Lab

Official academic, research, and educational portal for **Dr. Sourav Kumar Bhowmick**, Assistant Professor in the Department of Electronics at Asutosh College, Kolkata (affiliated with the University of Calcutta).

---

## 🌟 Overview & Features

- **Academic Profile & Credentials**: Ph.D. in Science from Jadavpur University & CSIR-IICB (*"Observation of synchronization in coupled chaotic oscillators"*), M.Sc. in Electronic Science from Jadavpur University, and B.Sc. from Vidyasagar University (3rd in University Merit List).
- **Research & Publications**: Full catalog of 19 peer-reviewed journal papers (Elsevier, Physical Review E, Physics Letters A, CHAOS, Springer) with DOI links, impact factors, and 1-click citation generators (APA & BibTeX).
- **Interactive Chaos Theory Simulator**: Real-time numerical phase space simulation of coupled chaotic oscillators and phase synchronization using HTML5 Canvas.
- **Courses & Study Materials (28 Resources)**:
  - Python interactive materials with Google Colab notebooks and customized Gemini AI Mentor (*Python: সৌরভ স্যার*).
  - Scilab on Cloud (Math Lab) & IIT Bombay Spoken Tutorials (C, Advance C, Scilab).
  - Arduino microcontroller programming, PSpice circuit simulations, PCB design, optical fibre communication, photonics, and e-PG Pathshala INFLIBNET modules.
- **University of Calcutta Question Bank**: Comprehensive past question papers for:
  - CBCS Semester system (2018 – 2025 Even & Odd Semesters).
  - CCF 4-Year Undergraduate NEP framework (2023 – 2026).
  - Official Calcutta University Paper Code reference index.
- **Practical Laboratory Manuals**: Semester-wise practical manuals for Semesters I through VIII covering circuit theorems, analog/digital electronics, op-amps, microprocessors, and communication kits.
- **Regulations & Syllabi**: CCF-UG CSR-123 Major & Minor Syllabi, 4th-Year Honours with Research syllabus, and Examination Modalities.
- **Global Search (⌘K / Ctrl+K)**: Instant indexing across all 80+ documents, courses, question papers, and publications.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone <your-github-repo-url>
cd <repo-name>

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Visit `http://localhost:3000` in your web browser.

### Build for Production

```bash
npm run build
npm run preview
```
